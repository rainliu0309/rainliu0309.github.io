PRODUCT IN ONE LINE · 一句话产品定义

A controlled multimodal narrative reflection tool for young adults navigating uncertain career, relationship, and life choices.

面向职业、关系与生活中不确定选择的年轻人的受控多模态叙事自省工具。

Project Snapshot · 项目概览

TARGET USER · 目标用户 Young adults navigating decision anxiety 正在应对决策焦虑的年轻人

For career, relationship, and life choices where a single answer does not resolve the uncertainty.面对职业、关系与生活选择时，单一答案无法消解不确定感。

BUSINESS LINE · 业务方向 Controlled reflection for decision anxiety 面向决策焦虑的受控自省体验

Three guided routes offer a longer view, a present mirror, and open dialogue for reflection.三条引导路径提供长期视角、当下映照与开放对话，帮助用户展开自省。

NORTH STAR · 核心目标 User-owned decisions, not model verdicts 判断权属于用户，而非模型结论

Each route offers perspectives and boundaries, while users decide what matters in real life.每条路径提供视角与边界，用户决定哪些内容对现实生活真正重要。

Limits & Boundaries · 局限与边界

01 / PRODUCT GAP Why linear AIGC falls short 为什么单线 AIGC 存在局限

Irreversible framing问题框架过早固化One prompt fixes the frame too early, so later questions inherit the same assumption.一次提问过早固定问题框架，后续追问容易沿用同一假设。

No visible comparison缺少可见对照Alternatives merge into one answer, making side-by-side comparison difficult.不同可能被合并进一个答案，难以进行横向比较。

Boundary opacity安全边界不透明Fluent language can hide uncertainty, product limits, and when a user needs real-world support.流畅语言会遮蔽不确定性、产品边界，以及何时需要回到现实支持。

State Rhythm · 状态节奏

STATE 01 · CONTEXT · 收集情境

Keep each route’s context separate.让每条路径只保留自己的情境

Zi Wei uses birth data and timezone; tarot keeps the question and fixed draw; open dialogue sends a capped conversation history. Context does not transfer across routes.

紫微使用生辰与时区；塔罗保留问题与固定抽牌；闲谈仅携带有限对话历史。不同路径之间不继承上下文。
STATE 02 · RULES · 规则解析

Create one fixed session snapshot.生成前先固定一次会话快照

Time-zone conversion, palace placement, card identity, orientation, and spread position are resolved in code before generation. Follow-ups preserve the same draw instead of redrawing.

生成前由代码确定时区、宫位、牌面、正逆位与牌阵位置；后续追问沿用同一次抽牌，不会重新抽取。
STATE 03 · REVEAL · 渐进披露

Expose one cognitive step at a time.一次只呈现一个认知步骤

The user chooses which path or card to reveal. Progress is explicit, user-controlled, and never ranked as good or bad.

由用户决定先看哪条路径或哪张牌；进度清楚、过程由用户控制，也没有好坏排序。
STATE 04 · REFLECT · 形成复盘

Convert reading into user-owned language.把解读转为用户自己的语言

Across the two symbolic routes, three multiple-choice prompts turn passive reading into a reflection card shaped by the user’s selections.

在两条符号通道中，三道选择题把被动阅读转成由用户选择共同形成的复盘卡片。
STATE 05 · RETURN · 现实对照

Place narrative beside what actually happened.让叙事与现实发生的事情并置

The local Choice Journal lets users revisit and compare records, add reality notes, or delete a record from this device.

本地“反宿命日志”支持回看与对照记录、添加现实备注，或从当前设备删除内容。

State Boundaries · 状态边界

ROUTE CONTEXT · 路由上下文 Each route holds only the context it needs. 紫微、塔罗与闲谈各自保存所需输入，不跨路径继承。
SESSION SNAPSHOT · 会话快照 Symbols are fixed before narration begins. 盘面与抽牌确定后才进入叙事，追问不重新抽牌。
LOCAL RECORD · 本地记录 Revisit, compare, annotate, or delete. 记录保存在当前设备，可回看、对照、添加现实备注或删除。
GUIDED PATHS · 受控路径 Reveal and revisit, rather than create branches. 支持渐进展开与路径回看，不提供手动创建、命名或合并分支。

03 AI SYSTEM DESIGN · AI 系统设计 Generation Guardrail & Boundary Rule Design 生成护栏与边界规则设计
ROLE SEPARATION · 职责分离

Code fixes symbols and boundaries first. The model only turns verified inputs into neutral, structured language.

代码先确定符号与边界，模型只将已验证的输入转为中立、结构化的叙事语言。

Responsibility Map · 职责地图

RULE ENGINE · 规则引擎 Fixes the symbolic structure 固定符号结构

Backend code determines time zones, chart structures, card identities, orientations, and spread positions before AI writing begins. The symbolic result is never generated by the model.模型写作开始前，后端代码已确定时区、盘面结构、牌面、正逆位与牌阵位置；符号结果不由模型生成。

OUTPUT CHECK · 输出校验 Validates output before display 展示前校验输出

Schema and required-field checks run before display. Incomplete or malformed results do not appear as finished experiences.展示前执行 Schema 与必填字段校验；不完整或格式异常的结果不会被呈现为完整体验。

NARRATIVE MODEL · 叙事模型 Turns rules into reflection 把规则写成自省叙事

Agnes turns verified rule results into neutral, readable reflection. An optional mood image can adjust tone, never the underlying result.Agnes 将已确定的规则结果写成中立、易读的自省叙事；可选心境图片只调整语气，不改变底层结果。

PATH EQUITY · 路径等权 Keeps neither path above the other 不把任一路径标成更好答案

The two Zi Wei paths share one safety boundary and equal visual weight. Users choose how they read, reflect, and act; the final decision stays with them.两条紫微路径共享同一安全边界与视觉权重；用户决定如何阅读、反思与行动，最终判断始终留给用户。

Model Permissions · 模型权限

MODEL MAY · 模型可以

  • Translate fixed symbols into neutral narratives 将固定符号转为中立叙事
  • Adapt wording from optional mood imagery 根据可选心境图片调整表达语气
  • Return validated emotion metadata for the interface 返回经校验、供界面使用的情绪元数据

MODEL MUST NOT · 模型不得

  • Calculate, redraw, or change symbolic results 计算、重抽或修改符号结果
  • Predict outcomes or frame either path as the right answer 预测现实结果，或把任一路径包装成正确答案
  • Use retrieval, function calls, tools, or agent loops 调用检索、函数、工具或自主循环

Runtime Safeguards · 运行保护

PREVENT · 前置约束 Fix symbols, bound prompts, and limit inputs before narration begins. 叙事开始前固定符号、约束提示词并限制输入范围。
VALIDATE · 运行校验 Check schema and required fields before the interface renders. 界面展示前校验 Schema 与必填字段。
INTERCEPT · 越界拦截 Sanitize unsafe language and surface a safety note for immediate risk. 清理越界语言，并为即时风险内容显示安全提示。
FAILURE · 请求失败 Show a clear message, fallback visual, and request ID when requests fail. 请求失败时显示明确提示、替代视觉与请求 ID。

Design Impact · 设计影响
01 · ENTRY · 入口引导 Soften the first decision把第一次选择变得更温和 Less pressure减少被推动感

The dominant start CTA made the first step feel directive, so it became a quieter invitation into three routes.

强势的开始按钮让第一步显得被推动，因此改成更克制的入口，引导用户进入三条路径。
02 · STAR PATH · 星轨推演 Reveal one path at a time一次只展开一条路径 Lower comparison load降低比较负担

Showing both paths together increased comparison load, so users reveal one route, then decide when to open the other.

同时展示两条路径会增加比较负担，因此先展开一条，再由用户决定何时打开另一条。
03 · TAROT · 塔罗 Make agency visible before interpretation先让用户看见自己的选择 More agency增强参与感

A full spread lets users choose three positions before the cards are revealed together, keeping agency visible before interpretation.

用户先从完整牌组中选择三个位置，再一起揭示牌面，让自主选择先于解释发生。
04 · HISTORY · 历史记录 Start with choices, then keep the record先选择，再保留记录 Easier revisiting更容易回看

Staged choices reduce response effort, and the resulting reflection card stays in local history for later comparison.

先用选择题降低作答负担，生成的复盘卡保存在本地历史中，方便之后回看对照。
