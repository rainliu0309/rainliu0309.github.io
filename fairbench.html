Build the 2,400-image set so every approved age, gender and ethnicity group has enough records to compare. Before an audit runs, FairBench shows the count for every group and flags any group below the minimum.

02Test hard cases too也要测试困难场景⌄

03Keep sensitive labels separate敏感标签与识别接口分离⌄

Age, gender and ethnicity labels stay in a protected audit table used only to compare group results. The face-recognition API receives the image, not these labels; reviewers see group totals and gaps, not raw identity data.

年龄、性别和族裔标签保存在受保护的审计表中，只用于比较人群结果。人脸识别接口只接收图像，不接收这些标签；审核人员看到的是分组数量和差异，而不是原始身份信息。Access · 访问原则

03 ROOT CAUSES 根因定位

The same score can come from different problems, so reviewers open the evidence behind the leading dimension before assigning an owner.相同分数可能由不同问题造成，因此审核人员会先展开主要风险维度背后的证据，再确定责任人。

01
Segment or dataset bias分组或数据集偏差

Check who is under-represented and which capture condition is missing.

检查哪些人群代表不足、哪些采集条件缺失。

What to check检查什么Compare group counts, corrected labels, rejected images and accuracy for side pose, low light and partial occlusion.对比分组数量、标签更正、被拒图像，以及侧脸、低光和局部遮挡下的准确率。

Who fixes it谁来修复The team that collects images and maintains labels.负责采集图像和维护标签的团队。

02
Model configuration or learned weights模型配置或学习权重问题

Check whether the same samples fail across versions or vendors.

检查相同样本是否在不同版本或供应商中持续失败。

What to check检查什么Compare the model version and confidence threshold, then see whether the same failed photos recur across vendors.对比模型版本和置信度阈值，并查看同一批失败照片是否在不同供应商处重复出现。

Who fixes it谁来修复The model vendor or the ML engineering team.模型供应商或机器学习工程团队。

03
Request, preprocessing or prompt design请求、预处理或提示设计问题
